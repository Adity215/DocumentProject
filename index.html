Introduction

JavaScript is a versatile programming language used in web development.

It can be used for both front-end and back-end development.

console.log("Hello, World!");
  • Used in browsers
  • Dynamic content
  • Interactivity
Variables

Variables are containers for storing data values.

Use var, let, or const to declare variables.

let x = 10; const name = "Alice";
  • var: function-scoped
  • let: block-scoped
  • const: block-scoped & constant
Functions

Functions are blocks of code that perform a task.

You can define functions using function keyword or arrow syntax.

function greet() { return "Hello"; } const greet = () => "Hello";
  • Reusable code
  • Can take parameters
  • Can return values
Loops

Loops let you repeat a block of code.

Common types include for, while, and do...while.

for (let i = 0; i < 5; i++) { console.log(i); } while (i < 5) { i++; }
  • for
  • while
  • do...while
Objects

Objects are collections of key-value pairs.

They are used to store structured data.

let person = { name: "Alice", age: 25 }; console.log(person.name);
  • Key-value pairs
  • Access with dot or bracket notation
  • Methods and properties
